These sustained vowels are synthesized by averaging eight steady vocal cycles from each human recording, removing frequencies above 8 kHz, normalizing, and repeating that single cycle as mono 48 kHz WAV. This removes pauses and the repeating syllable envelope. Each modified recording is licensed under CC BY-SA 3.0.
